v0.3.4

画面端までドラッグしたときの収納を修正

  • ウィンドウの一部が画面端を越えても吸着し、ポインタを離すと半円に収納されます。
  • 小さい表示と展開した表示のどちらでも左右に吸着し、画面内へ戻すとフローティング表示になります。

v0.3.3

画面端への収納とサービス別の色

  • 浮島を画面の左右にドラッグすると、マウスを離した後に半円へ収納されます。重ねるかクリックすると展開し、画面端からドラッグすると通常の表示に戻ります。
  • ディスプレイ、左右の位置、高さを保存し、再起動後も復元します。待機中も半円からパネルを開けます。
  • Claude はオレンジ、Codex CLI とデスクトップは青紫で表示します。承認待ち、完了、失敗は別の記号で示します。

v0.3.2

会話への移動とツール状態の修正

  • CLI の会話 ID とデスクトップの会話 ID を照合し、Claude の対象会話を開きます。
  • 別のバックグラウンド接続を使った Codex の移動判定をやめ、誤ったエラー表示を修正しました。
  • ツール名を表示し、コマンド出力、JSON、トークン、内部呼び出し ID を状態ラベルに表示しません。

v0.3.1 と v0.3.0 の改善

メインスレッドの処理を減らし、動きを滑らかに。

docs/release.json は GitHub Releases に公開中の v0.3.4 パッケージを記録し、ダウンロード、チェックサム、Homebrew cask は同じメタデータから生成されます。

バックグラウンド読み取り

  • 読み取り専用の SQLite クエリをアプリ内で実行し、更新ごとの外部プロセス起動を省きます。
  • Hook がファイルパスを渡した場合、履歴ディレクトリの探索を省きます。

一貫したタスク状態

  • Hook の状態をすぐに表示し、古い読み取り結果が新しいイベントを上書きしないようにします。
  • 更新結果を一度に反映し、DB の読み取りに失敗しても既存のタスクを保持します。

画面とアニメーションを刷新

  • 暗いグラファイト色に淡い青紫の静的グラデーションを加え、読みやすい文字と明瞭な承認ボタンを採用しました。重なるぼかしと発光枠を減らしました。
  • 開閉中にクリックしても速度を保って滑らかに切り替わり、文字の配置は変わりません。
  • 非表示時はサイズ変更と回転のアニメーションを停止します。
  • 回転、呼吸、ピクセル表示がシステムの「視差効果を減らす」に従います。

承認待ちの保持

  • 表示件数の上限を超えても承認待ちは保持します。
  • Codex Desktop を無効にすると、接続確認プロセスも起動しません。

主要機能

v0.1.0 に含まれる内容。

画面上部のステータスアイランド

  • AI コーディングの活動状態、最近のツール実行、状態サマリーを macOS 上部に表示します。
  • アイドル時は小さく、長い処理や重要な状態では展開します。
  • Claude Code、Codex CLI、Codex Desktop の並行ワークフロー向けです。

ローカル承認処理

  • 一回許可、セッション中の許可（対応時）、拒否、タスク取消を macOS ネイティブの画面で処理します。Codex CLI Hook の承認は許可または拒否のみです。
  • 承認処理に必要な基本的な文脈を保持します。
  • ターミナル、デスクトップクライアント、ログ間の切り替えを減らします。

ソースとローカル接続

  • Claude Code、Codex CLI、Codex Desktop のソースを個別に有効化できます。
  • 設定画面からローカル接続をインストール、修復、アンインストールできます。
  • 接続の実行ファイルとログは Mac 内に残り、排障と整理に使えます。

ローカルファースト境界

  • このアプリはアカウント作成、テレメトリ送信、リモートセッション同期を行いません。
  • 主要な状態表示、ソース制御、承認処理は Mac 内で動作します。
  • プライバシーページで読み取り、書き込み、ネットワーク境界を説明しています。

既知の境界

v0.1.0 の製品範囲。

v0.1.0 は macOS 14+ 上のローカル状態表示と承認処理に焦点を当てています。Claude Code、Codex CLI、Codex Desktop はそれぞれのアカウント、ネットワーク、セッション動作を保ちます。Vibelsland Free は Mac 上で利用できるローカル状態を整理し、ソースごとに表示を制御できるようにします。
