v0.3.0 新增

减少主线程工作，保持动画连续。

docs/release.json 记录当前发布到 GitHub Releases 的 v0.3.0 包；下载、校验和与 Homebrew cask 均由同一份元数据生成。

后台读取

  • 使用进程内只读 SQLite 查询，省去每次刷新启动外部进程。
  • Hook 提供文件路径时直接读取，不再遍历全部历史目录。

一致的任务状态

  • Hook 状态立即显示，后台补充会话内容，过期结果不会覆盖新事件。
  • 一次刷新只发布最终状态；数据库读取失败时保留上次任务。

重新设计的界面与动画

  • 深石墨底色配上淡蓝紫静态渐变、清晰的文字层级和高对比度审批按钮，减少多层毛玻璃与发光边框。
  • 展开和收起使用保留速度的阻尼动画，连续点击也能自然转向，文字排版保持稳定。
  • 隐藏窗口会停止帧动画和旋转动画，恢复显示后按当前状态继续。
  • 旋转、呼吸与像素提示响应系统“减弱动态效果”。

审批保留

  • 显示数量上限不会再丢弃待处理审批。
  • 关闭 Codex Desktop 来源后不再启动连接检测进程。

主要功能

v0.1.0 包含的核心能力。

顶部浮岛状态显示

  • 把 AI 编程会话的活动状态、最近工具调用和状态摘要保持在屏幕顶部。
  • 空闲时收起，长任务运行和关键状态出现时展开。
  • 面向 Claude Code、Codex CLI 和 Codex Desktop 的并行工作流。

本地审批处理

  • 在 macOS 原生界面中处理允许一次、本轮允许（支持时）、拒绝和取消任务；Codex CLI Hook 审批只支持允许或拒绝。
  • 保留处理审批所需的基本上下文。
  • 减少在终端、桌面客户端和日志之间切换的频率。

来源与本地连接

  • 按来源启用 Claude Code、Codex CLI 和 Codex Desktop 状态。
  • 通过设置页安装、修复或卸载本地连接。
  • 连接运行文件和日志保留在本机，便于排障和清理。

本地优先边界

  • 无需创建账号，也不上传遥测或远程同步会话内容。
  • 核心状态显示、来源控制和审批处理在本机完成。
  • 隐私页说明了读取、写入和网络边界。

已知边界

v0.1.0 的产品范围。

v0.1.0 聚焦 macOS 14+ 上的本地状态显示和审批处理。Claude Code、Codex CLI 与 Codex Desktop 仍保留各自的账号、网络和会话行为；Vibelsland Free 只整理本机可用状态，并让你按来源控制展示。
