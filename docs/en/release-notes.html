v0.3.4

Fix docking when a drag crosses the screen edge

  • The island now docks even when part of the window moves past the screen edge, then collapses when the pointer leaves.
  • Compact and expanded windows both dock on either side and return to floating when dragged back into the screen.

v0.3.3

Edge docking and provider colors

  • Drag the island to either side of the display to dock it as a semicircular tab. Hover or click to open it, and drag away to restore a floating panel.
  • The display, side, and height are saved across restarts. An idle dock remains visible and accessible.
  • Claude rings are orange; Codex CLI and Desktop rings use a blue-to-violet gradient. Separate symbols indicate approval, completion, and failure.

v0.3.2

Session navigation and clear tool status

  • Claude cards resolve the CLI session ID to the existing desktop conversation.
  • Codex navigation no longer mistakes a separate background connection for the desktop selection.
  • Tool badges show tool names instead of command output, JSON, tokens, or internal call IDs.

Improvements in v0.3.1 and v0.3.0

Less main-thread work, continuous window motion.

docs/release.json records the v0.3.4 package currently published on GitHub Releases; the download, checksum, and Homebrew cask are all generated from the same metadata.

Background reads

  • Read-only SQLite queries run in process, without spawning a command for every refresh.
  • Explicit Hook transcript paths bypass history-directory discovery.

Consistent session state

  • Hook status appears immediately; background transcript results cannot overwrite newer events.
  • Each refresh publishes its final state once; failed database reads preserve existing sessions.

Redesigned interface and motion

  • A dark graphite surface with subtle static blue-to-violet gradients, clearer typography and high-contrast approval actions replaces stacked glass effects and glow borders.
  • Interruptible, damped window motion retains velocity during repeated clicks while text keeps a stable layout.
  • Hidden windows stop frame and spinner animations and resume from current state when shown.
  • Spinners, breathing lights and pixel indicators respect Reduce Motion.

Approval retention

  • Pending approvals are retained beyond the visible-session limit.
  • Disabling Codex Desktop also skips its connection probe process.

v0.3.1

v0.3.1: startup animation.

A new launch entrance fades and gently scales the real island at its final position, settling in about half a second. The separate center-screen intro and 2.2-second wait are gone. Clicks, approvals and settings interrupt the entrance immediately. Includes the subtle gradients and background-read improvements from v0.3.0.

Key features

What v0.1.0 includes.

Top-of-screen status island

  • Keeps AI coding activity, recent tool calls, and status summaries at the top of macOS.
  • Contracts while idle and expands for long-running work or important state.
  • Designed around parallel Claude Code, Codex CLI, and Codex Desktop workflows.

Local approval handling

  • Handles accept once, accept for session where supported, decline, and cancel task actions in a native macOS surface; Codex CLI hook approvals support only allow or deny.
  • Preserves the basic context needed to handle approvals.
  • Reduces switching between terminals, desktop clients, and logs.

Sources and local connections

  • Enables Claude Code, Codex CLI, and Codex Desktop sources independently.
  • Installs, repairs, or uninstalls local connections from the settings page.
  • Keeps connection runtime files and logs local for troubleshooting and cleanup.

Local-first boundary

  • No account creation, telemetry upload, or remote session sync from this app.
  • Core status display, source controls, and approval handling run on the Mac.
  • The privacy page describes read, write, and network boundaries.

Known boundaries

The v0.1.0 product scope.

v0.1.0 focuses on local status display and approval handling on macOS 14+. Claude Code, Codex CLI, and Codex Desktop keep their own account, network, and session behavior; Vibelsland Free organizes the local state available on your Mac and lets you control what appears by source.
